# Echo Garden — Week 3 asset integration

Prepared for Sarthak Shelar • Submission date 03/11/2026

Three playable puzzle rooms with file-based SVG artwork, character animation, visual effects, sound effects and an ambient melody. This continues the browser prototype from Week 2; the puzzle rules in `core.js` are unchanged.

## Play

1. Extract the entire archive.
2. Open `index.html` in a current desktop browser. Keep all files and the `assets` folder together.
3. Click **Effects: off** or **Music: off** to enable audio. Both start off. These are separate toggles.
4. Use arrow keys/WASD to move, Space to wait, E to record/finish, Enter to activate the terminal, R/Backspace to reset. Pointer controls are also available.

No build or internet connection is required. If local files are restricted by your browser, run `python -m http.server 8000` in this directory, then visit `http://localhost:8000`. Python is only needed for this optional server and the asset-generation script.

## New files and asset organization

- `assets/art/`: 17 editable, self-contained 96×96 SVG images.
- `assets/audio/`: 5 sound cues and one 8-second ambient WAV melody.
- `assets/manifest.json`: exact inventory, roles and technical properties.
- `assets/ASSET_SHEET.png`: visual contact sheet, not a browser screenshot.
- `assets.js`: image loading, failure notices and opt-in audio.
- `renderer.js`: tile rendering, character frames, 150 ms movement interpolation, gate flash and restoration particles.
- `state.js`: shared state and browser progress storage.
- `game.js`: UI and action feedback.
- `tools/make_assets.py`: reproduces all 23 runtime assets with Python's standard library.
- `Echo_Garden_Week3_Report.docx`: submission report.
- `SUBMISSION_DESCRIPTION.txt`: over 200 words for the form.

## Creation method and provenance

Artwork is drawn from SVG paths and shapes using a shared garden palette. No external image or audio packs are used. The audio is synthesized from sine tones, harmonics and envelopes and written as mono 16-bit PCM at 22,050 Hz. The code and assets were prepared with AI assistance; no Photoshop, Blender or Audacity workflow or logged work hours are claimed. Review the files and follow your internship's rules on assisted work.

The SVG files are the editable visual source. `tools/make_assets.py` is the editable source for the sound designs. To regenerate, run `python tools/make_assets.py`. The contact sheet and report are documentation, not regenerated by that script.

## Animation and accessibility

Three wheel frames and a blink frame are supplied for both Pip and the outlined Echo. The runtime selects movement frames and an occasional blink. The player and Echo move smoothly between turn-based tile positions; state changes still happen immediately and deterministically. Gates switch artwork and briefly flash. Restored rooms change floor tiles and emit a short particle burst.

Operating-system reduced-motion preference disables frame cycling, interpolation, gate flash and particles. Gate and terminal state remain visible. Sound is optional and has visual equivalents. There is no music-autoplay attempt.

## Manual check before submission

- Open all three rooms. Confirm artwork loads and controls remain readable when resizing.
- Turn effects on; move, record, reset, open a gate and finish a room. Listen for the matching cue.
- Turn music on; listen through a loop, then turn it off. Check effects and music can be controlled separately.
- Check the Echo stays recognizable, the gate changes state, and recording/reset still work.
- Enable reduced motion in your OS and reload; confirm gameplay works without animated effects.

The music loop has a short quiet transition; it is not claimed to be a seamless soundscape. The route overlay assumes closed gates; the command strip and actual replay remain authoritative. Save behavior for local file URLs varies by browser. Missing artwork uses letter fallbacks and a recovery notice. Audio failures do not block play.
